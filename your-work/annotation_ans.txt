 30. [R146] Process to Set Up Repetitive Wire Transfers
The State has three communication options to establish repetitive wire transfers:
1.  Internet (SinglePoint): Program Administrators can request repeat codes online directly through SinglePoint. They can also create wire transfer templates that store repetitive wire data. For security, SinglePoint templates are treated as non-repetitive transactions because they can be modified by a single authorized user.
2.  Mail: If SinglePoint is not utilized, mailing the bank's authorized request form is the standard manual method to establish repeat codes.
3.  Other / Repetitive Form: Administrators can complete the physical Wire Transfer Repetitive Transfer Authorization form. Once established, these repeat codes are uploaded into SinglePoint for easy online execution. If utilizing a CPU-to-CPU batch wire system, repeat codes can be embedded directly within the State's transmitted files.
   Turnaround Time: Online requests for repeat codes are processed and ready for use within five business days. U.S. Bank provides both an online confirmation message and a mailed physical confirmation when the repeat code is active.
