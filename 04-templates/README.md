# Templates

Copy these into `your-work/` and fill them in. Don't edit them here — leave the blanks
for the next person.

| Template | For | Copy to |
|---|---|---|
| [research-log-template.md](research-log-template.md) | Every day, from day one | `your-work/research-log.md` |
| [questions-template.md](questions-template.md) | Every day, from day one | `your-work/questions.md` |
| [annotation-summary-template.md](annotation-summary-template.md) | Task 1 | `your-work/annotation-summary.md` |
| [source-candidate-log.md](source-candidate-log.md) | Task 2, filled in as you go | `your-work/source-candidate-log.md` |
| [sourcing-findings-template.md](sourcing-findings-template.md) | Task 2 write-up | `your-work/sourcing-findings.md` |
| [research-memo-template.md](research-memo-template.md) | Tasks 3 and 4 | `your-work/<topic>.md` |

Task 5's deliverable has no template — its structure is in the brief itself.

**The structure isn't decoration.** Each of these separates *what you found* from *what
you concluded*, and asks explicitly what you couldn't determine. That's the house style
(see [../01-context/how-we-work.md](../01-context/how-we-work.md)) and it's what makes a
deliverable checkable by someone who wasn't there.

Add sections if you need them. Don't drop the "what I could not determine" one.
